其他支持 Skill 的工具可使用其规定的安装目录；也可以让助手直接读取该文件夹中的 `SKILL.md`。这是一套可复用的制作流程，不是现成场景模板，也不保证任意参考图都能一次生成成品。复杂构图和动画仍需逐步验证、调整。

根据用户的溪边回廊、古树与木桥参考图搭建的程序化 Three.js 小景。竖向古树、紧凑庭院、自然溪岸和深色轮廓形成适合手机的插画构图；细像素采样、有限色阶和最近邻纹理保留原有质感。像素模式每个画面采样约对应 2×2 CSS 像素，支持高分辨率屏幕，保留旋转与放大观察。建筑、植物、季节人物与动物、鱼、水、纹理、天气均由代码生成。没有下载的图片、模型、音效、HDR 或网络字体。Three.js 和 React 作为程序依赖本地打包。

## 手机构图与轮廓

厚重的正方形底座已移除。土地、溪底和水面都使用不规则边界，岸边保持很薄的收口，只有接触溪水的位置保留自然斜坡。左岸花地收小，右侧树冠收拢，古树上部增高，并在中层补充分叉、细枝和连续叶簇，向右伸出的粗枝与叶簇覆盖部分屋顶；根部、院内用品和四季事件的活动空间保持支撑关系。场景铺满整个视口，标题和控制栏浮在上层。手机默认视角将小景稍微下移，仍为主体留出阅读空间，放大或拖动后景物可延展到界面下方，不再被中间矩形窗口截断；也支持横屏和桌面。

描边依据可见几何的深度和法线生成，重点勾勒房屋、古树、物件和地面边缘；细小花草、水纹与透明光效不叠加墨线。原生模式的轮廓约一个 CSS 像素，像素模式约占一个像素格，避免把木纹或每一块色彩变化都变成黑边。参考了 Three.js 官方的 [RenderPixelatedPass](https://threejs.org/docs/pages/RenderPixelatedPass.html) 与 [OutlinePass](https://threejs.org/docs/pages/OutlinePass.html)；最终使用自定义合成通道。

## 使用

- 春夏秋冬切换树木、草地与花期、荷叶、道具和季节小事件。所有事件自动发生；暂停按钮同时暂停它们。
- 时间自动流动，摆设和小事件随昼夜变化。太阳/月亮按钮可跳到正午或夜晚。春夏秋可选晴天或雨天；冬天可选晴天或下雪，不再提供下雨。春夜下雨时有偶发的远雷和柔和云光。
- 单指或鼠标左键拖动旋转；双指平移并可捏合缩放，鼠标右键平移、滚轮缩放。上下方向均可平移；轻点未冻结的水面产生涟漪。
- 支持暂停、背景音乐、恢复视角、保存画面、全屏。
- 声音按钮仅控制六首背景音乐；原先合成的风、雨、雷与风铃音效均已移除。歌单从两首《春の雨音》开始，依次播放两首《蝉時雨の縁側》和两首《Maple Room》，播完后循环；音乐默认开启；浏览器限制自动播放时，首次点击或触摸后开始播放。
- 右上角“中 / EN”可切换完整中文与英文界面。中文界面仅保留语言入口里的“EN”，标题、季节、时辰、状态和控制均使用中文；英文界面替换整套可见文案与辅助阅读标签。昼夜只显示太阳和月亮图标。
- 恢复视角、保存画面和全屏按钮在右上角两行文字下方无框竖排，按钮随视口保持 28–34px，图标 14–18px。
- 底部控制去掉底色、边框、阴影和模糊层，以纯文字、线性图标、细分隔线和少量强调色悬浮在画面上。宽屏横排季节与设置，手机竖屏分行；时辰栏独立一行。全屏时隐藏操作提示并把控制贴近屏幕底部，宽屏合为一行。
- 点太阳/月亮时，庭院用约 4 秒连续经过日出或日落；自动时钟自然穿过晨昏，不再在地平线处切换整幅快照。直接拖动时辰时使用 1.2 秒旧画面淡出，底图始终保持完整透明度，避免中途变暗；画风切换仍为约 0.4 秒。界面不参与画面淡化。
- 底部从左到右点选“原生 / 像素”，首次打开默认原生画风。像素模式每格约 2×2 CSS 像素，含有限色阶与轻微抖动；原生模式使用屏幕渲染分辨率和平滑纹理，夜景保留少量暖色高光泛光。画风切换沿用约 0.4 秒画面淡化，雪花和萤火虫在像素模式保底占一个格子。
- 现实 6 分钟为庭院一日、12 分钟为一个季节，48 分钟走完四季。初始夏日巳时 10:00，十二时辰随时间轮替。拖动时间滑条可观察晨昏；“时间停留”只停止日月与四季，“暂停动画”同时冻结时间和庭院动画。网页放到后台时不快进；手动选季节后重新计算该季的 12 分钟。
- 天空中的小太阳与弯月沿时间移动，清晨/傍晚光偏暖、影子较长，午间日照升高；月光与水面反光的方向一起变化。夏季昼长、冬季昼短，季节交界的日月方向连续。使用适合庭院的艺术化日月轨迹，月相不做真实天文历法模拟。
- 日光在地平线附近减弱到零，晨昏范围扩大到太阳高度正负 12 度；日出偏淡粉、日落偏杏橙，低空太阳也变暖。月光只负责夜间冷色照明与水面反光，不投射第二套实体阴影，避免日夜交接时出现方向相反的双影。
- 自动流转每 60–120 秒抽取一次天气（首次 60 秒）。每次抽取的降水概率：春雨 62%、夏雨 28%、秋雨 34%、冬季白天雪 42%、冬夜雪 76%，其余为晴天。这些是庭院氛围概率，不代表真实气候。手选天气后保留 120 秒，再恢复抽取；暂停、停止自动流转和后台时间不计入等待。云色与雨雪渐入渐出，春夏秋不下雪、冬季不下雨。

- `app/terrain-footprint.ts`：不规则薄地面、溪岸斜坡、溪底和水面边界。

- `app/canopy-fall.ts`：按真实树冠采样起点、沿风路落下并在承接面停留淡出的落叶。
- `app/garden-atmosphere.ts`：共享阵风、春夜雷雨和小型夜蝶。
- `app/day-night-life.ts`：昼夜茶歇、被褥和夏夜关闭的障子门。
- `app/snow-accumulation.ts`：有限厚度的积雪和池化的檐口落雪。
- `app/winter-creek-ice.ts`：沿实际河岸延伸的薄冰、霜边与细裂纹，中央流水和饮水口保持开放。
- `app/garden-life.ts`：无护栏旧木桥、农具架与自行车。
- `app/garden-planting.ts`：左岸小片四季花地与夏季浮动荷叶。
- `app/curved-grass.ts`：根部固定的分段弯草、粉色春芽与同步微风。
- `app/roof-leaves.ts`：贴合真实瓦面的秋日落叶。
- `app/seasonal-fauna.ts`：秋日松鼠、小鸟飞行与饮水，以及季节事件控制。
- `app/spring-cat.ts`：小体量橘白睡猫，连续躯干、贴合表面的毛色分区与轻微呼吸。
- `app/summer-sleeper.ts`：夏日回廊午睡人物，书本盖脸与轻微呼吸。
- `app/snow-surface.ts`：顺着真实枝干和岸石表面的积雪。
- `app/water-surface.ts`：细碎水波与随视角变化的银蓝月色，减弱局部灯光镜面高光。
- `app/water-current.ts`：沿河道移动、两端收细的细长水光。
- `app/veranda-plant.ts`：带盆沿、土壤和完整绿色曲面叶片的回廊盆栽。

- `scripts/build-offline.mjs`：生成单文件离线 HTML（包含 Three.js 等依赖）。

## 四季风物

- 春：主古树与右侧小树均为深浅粉色花冠，粉色花瓣随风飘落；地面带柔和粉灰和嫩绿，弯曲草叶间生出粉色新芽、零星闭合花苞。草叶从固定根部逐渐弯向风中；树干爬藤稀疏，橘白小猫在回廊蜷睡，偶尔轻动耳朵。
- 夏：花地盛放、荷叶浮动，树冠枝繁叶茂；人物横躺在右侧檐下木回廊，书盖住脸，左膝轻曲、右腿伸直；扇子在右腿旁，西瓜和冷茶在头侧后方。电风扇放在右侧榻榻米上朝向人物，夏天右廊盆栽隐藏。
- 秋：花谢，只余少量枯梗；暖色落叶散在树冠下方的屋瓦并贴合瓦面，落叶铺地、爬藤橙黄；松鼠以较丰满的四肢快速跑一小段、停稳，再下树翻找松果并返回树背面；肘膝随固定脚掌落点弯曲。花瓶移至矮桌，瓶中植物缩小；柿子、无托盘的茶具和缩至 2/3 的书放在右廊，书在柿子左侧，右廊盆栽隐藏。
- 冬：树干爬藤消失，薄雪沿枝干上方连续覆盖，岸石雪层贴合原石轮廓；白头黑尾小鸟停在伸向屋顶的横枝上，先向左侧树外缘下降，再平滑右转对准低岸石，最后一段保持直线，不在落地前掉头；低头快速轻点两次、抬头休息，再从屋顶前方的开阔处绕弧线升高，减速落回横枝。飞行时身体保持接近水平，只随转弯轻微侧倾；脚趾贴合横枝的真实雪面。

进入对应季节后，小事件很快开始；松鼠约 48 秒一个过程，小鸟约 52 秒。休息、活动和返回各有间隔。使用场景的统一时间，无外部 API、计时器或联网资源。

古树落叶从当季可见叶簇的实际位置发出，按高度分层覆盖高低树冠；原地形和道具的随机布局保持不变。约每26秒一阵风，风铃、树叶和落叶共用同一风势。树叶随风转动，遇到屋顶、木板、石头、土地或溪水后逐渐放平、短暂停留并淡出。春夏疏落、秋季增多，冬季停止飘叶。

春秋冬夜景保留温暖的室内灯；夏夜关闭室内主灯和纸灯自发光，走廊只留下室外灯附近的柔光。水面以银蓝月色为主，反光随视角和细波破碎变化；雨雪天气减弱月光。沿河道缓慢流动的细长亮线两端收细并轻微明暗变化。

场景结构检查覆盖 24 种季节、昼夜与天气组合，包含几何有效性、季节显隐、动画暂停与资源释放。额外验证季节草地与花苞数量、爬藤显隐、雪面朝向和附着、睡猫与午睡人物的地面支撑、松鼠完整往返与拾取、小鸟完整飞行与鸟喙接触溪水，以及已有木桥、荷叶和回廊道具的空间关系。该检查不替代浏览器或 GPU 视觉验证。

## 摆放与动作修整

公共坐垫完整放在同一片木地板上，底面高度与地板一致。春日茶点合在右侧回廊同一托盘，猫稍往右移并与茶盘留有间距。午睡人物、茶具、切片西瓜与柱子留有间距。夏季右廊留空给午睡和茶点，秋季右廊整理为阅读、喝茶的小角落。右廊盆栽已在四季全部移除。冬日炭盆向廊外移，左侧改为无托盘的汤碗。左侧盆栽重做成带厚度的绿色弯叶，去掉未着色白片。小鸟每组两次轻点只由头颈完成，双脚保持在平缓岸石上，饮水点邻近的三块岸石同步压低，尾羽抬起避开岸边。身体不再整块反复翻转，白色羽毛颈部随探头连接胸部与后脑。

## 夜晚与天气

春猫白天睡在檐下，夜晚换到树根右前方、回廊下的草地，换位时短暂淡出淡入；春夜收起茶点，室内铺上带枕头的被褥。夏夜收起午睡人物、西瓜、茶与扇子，整面障子门关闭，纸面贴合格栅，并加上连续不透明背衬封住斜视门缝。花地、溪水和右岸的萤火虫以约7个屏幕像素的柔光呈现。秋夜收起茶歇、松鼠休息，书仍留在回廊，只有几只小蝶掠过。冬夜保留炭盆、收起汤碗和桌上的食物，旁边添上折叠被。

右下角石灯的光源位于灯芯实际位置；风铃旁和树根右前方各有一盏小灯，随夜色渐亮。夜雨为低亮度的细蓝灰雨线；雷雨只在春季夜雨中发生，雷电仅保留视觉表现。冬季雪花采用约3.5–7.6个屏幕像素的大小层次，随风缓慢飘落，修正正交相机下原先不足一个像素的粒子尺寸。积雪有上限：屋瓦、桥板和少量空地逐渐加厚，旧树枝和小鸟落脚面保持原高度；晴天缓慢消退，离开冬季重置。檐口少量雪块先滑动再受重力落下，落地停留后淡出，最多复用8块，没有使用完整物理引擎。

冬溪两岸约五分之一的水面覆有不规则薄冰，边缘贴着水位，带浅灰蓝透色、窄霜边和少量细裂纹；中央水道、木桥支撑周围和小鸟饮水口保留流水。冰下流线与涟漪被冰面遮挡，点击冰面不产生水波。

夜雨使用蓝灰窄雨带和三档透明度，原生模式约一个 CSS 像素宽；2 像素模式绘制较少、更清楚的雨带，避免被采样抹掉。真实屋顶拦截雨滴后不再产生屋顶下方的河面水花，冬季仍没有下雨。
